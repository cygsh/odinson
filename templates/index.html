About Odinson

A low-cost digital seismometer: an MPU6050 accelerometer on an Arduino streams 3-axis acceleration at 20 Hz over USB serial to this Python gateway. An adaptive exponentially-weighted baseline tracks ambient vibration; deviations (delta) above the threshold trigger alerts via Telegram, AWS SNS email, and an audible beep.

Every reading is stored in SQLite locally and streamed to DynamoDB, CloudWatch, and S3 on AWS — provisioned with a single CloudFormation template.
