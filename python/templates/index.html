About the Project

The Odinson Vibration Monitor is a low-cost digital seismometer prototype that uses an MPU6050 accelerometer to detect and analyze vibration patterns in real-time. The system processes three-axis acceleration data, calculates a dynamic baseline, and triggers alerts when abnormal motion exceeds predefined thresholds.

Features include real-time waveform visualization, audible alerts, Telegram notifications, and CSV data logging for post-event analysis. The monitoring system is designed for structural health monitoring, earthquake early warning detection, and industrial vibration analysis.
